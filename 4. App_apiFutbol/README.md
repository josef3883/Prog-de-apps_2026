# 4. App_apiFutbol

Aplicación Flutter que consulta y muestra próximos partidos y resultados de la
Premier League y la UEFA Champions League desde la API gratuita
[TheSportsDB](https://www.thesportsdb.com/).

## Ejecutar en VS Code

Desde esta carpeta:

```bash
flutter pub get
flutter run
```

La app incluye búsqueda por equipo, actualización manual, gesto de refrescar,
escudos de los equipos, marcadores de partidos finalizados y vídeos destacados
de ScoreBat que se pueden abrir desde la app. También muestra mensajes para
estados de carga, resultados vacíos y errores de red.
